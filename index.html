      OUR DAA PROJECT

      Finding the smarter way around.

      ShopNavigator is an interactive, multi-floor mall navigation simulation that demonstrates how graph algorithms find shortest paths between locations.

      View project on GitHub ↗
      01 — THE IDEA

      Navigation meets algorithms.

      ShopNavigator models a multi-floor mall as a weighted graph. Stores, entrances and junctions represent vertices, while corridors and floor connections represent weighted edges. Users can select a starting point and destination and observe how shortest-path algorithms explore the graph.

      02 — THE ALGORITHMS

      Two approaches. One destination.

      GREEDY APPROACH

      Dijkstra's Algorithm

      Uses a min-heap priority queue to process the unvisited location with the smallest known distance. It is suitable for graphs with non-negative edge weights.

      Time complexity O((V + E) log V)
      Auxiliary space in this implementation O(V + E)
      EDGE RELAXATION

      Bellman–Ford

      Repeatedly scans graph edges and updates distance estimates over successive passes. It can handle negative edge weights when no reachable negative-weight cycle invalidates the result.

      Time complexity O(V × E)
      Auxiliary space O(V)

      How do they differ in ShopNavigator?

      Dijkstra processes locations according to their smallest tentative distance, while Bellman–Ford repeatedly scans edges in iteration order. When equal-cost alternatives exist, their tie-breaking and processing order can result in different selected routes with the same minimum cost. Different routes are not guaranteed for every selection.

      This simulation uses non-negative corridor costs and optional accessibility and crowd penalties to explore route selection.
