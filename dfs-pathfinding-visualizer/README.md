# DFS Pathfinding Visualizer

An interactive web-based demonstration of Depth-First Search (DFS) for pathfinding.

## Features
- Interactive pathfinding visualization
- DFS traversal demonstration
- HTML, CSS, and JavaScript implementation

## How to Run
1. Open `index.html` in a web browser.
2. Interact with the available controls to explore the visualization.

## Technologies
- HTML
- CSS
- JavaScript
