      Dijkstra's Algorithm
      Priority queue
      Time complexity
      O((V + E) log V)

      Explores the nearest known location first. Efficient for our mall's non-negative route costs.

      Nearest node→Update distances→Repeat
      ⟳
      Bellman–Ford
      Repeated edge relaxation
      Time complexity
      O(V × E)

      Repeatedly checks connections and improves distance estimates over multiple passes.

      Check edges→Improve distances→Repeat
      V = number of locations · E = number of connections · Space used by each: O(V)

      Worst-case estimate for this graph: Dijkstra ≈ basic steps; Bellman–Ford ≈ edge checks.
